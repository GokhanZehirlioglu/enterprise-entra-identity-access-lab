# Project Charter

## Mission
Design, implement and validate a secure Microsoft Entra identity and access baseline for a realistic fictional organization.

## Scenario
**WEZ – Wirtschafts- und Europaforschungszentrum** is a fictional independent economic and European research institute created exclusively for this lab.

The organization includes researchers, managers, finance users, IT support, privileged administrators, emergency accounts and external guests with different access needs.

## Target Signal
This project demonstrates readiness for a **Junior Cloud / Identity Engineer** path. It does **not** claim production IAM Engineer experience.

## Core Principles
- Least privilege
- Zero Trust
- Group-based access
- Separate standard and privileged identities
- Controlled privileged access
- Safe Conditional Access rollout
- Emergency access resilience
- Auditability
- Reproducibility
- Troubleshooting before guesswork
- Automation where repetition creates value

## Quality Standard
For important controls, capture:
1. Problem / Requirement
2. Design Decision
3. Implementation
4. Validation / Test
5. Failure Scenario
6. Troubleshooting / Root Cause
7. Rollback / Recovery
8. Lesson Learned
